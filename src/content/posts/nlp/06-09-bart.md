## 动机与定位

[GPT](/posts/nlp/06-08b-gpt/) 单向自回归生成，但缺乏双向语境，捕获输入语义整体性不足；[BERT](/posts/nlp/06-07-bert/) 双向编码擅长理解，但掩码机制和预训练目标限制了生成表现。BART（Bidirectional and Auto-Regressive Transformers）想同时满足自然语言**生成**和**理解**的需求，可以看作“BERT 的双向编码器 + GPT 的自回归解码器”的组合：

- **编码器**是双向 Transformer，可同时利用左右上下文；
- **解码器**是自回归 Transformer，从左到右生成输出；
- 预训练目标是**去噪**：对原文加噪，让模型还原原文。

## 结构

标准 Transformer encoder-decoder，另有两处工程改动：

- 激活函数用 **GeLU**（Gaussian Error Linear Unit），相比 ReLU 梯度更平滑，提高训练效率和性能；
- 参数初始化采用正态分布 $\mathcal{N}(0, 0.02^2)$，训练初期收敛更稳定。

编码器最后一层隐藏表示直接参与解码器计算（cross-attention），因此解码器每一步都能看到完整的加噪文本上下文，与 BERT 只独立预测掩码位置的机制有显著区别。

## 预训练任务：去噪自编码

BART 通过 5 种方式在输入文本中引入噪声（可组合使用），覆盖词、句、文档三个层次，解码器以自回归方式重建原文：

| 方式 | 操作 | 模型需要学到什么 |
| --- | --- | --- |
| Token Masking 单词掩码 | 随机把 token 替换为 `[MASK]` | 根据上下文填补单词 |
| Text Infilling 文本填充 | 把连续片段替换为单个 `[MASK]`，片段长度服从 Poisson($\lambda=3$) | 判断片段长度并重建内容 |
| Token Deletion 单词删除 | 随机删除 token | 预测缺失词**及其位置** |
| Sentence Permutation 句子排列变换 | 打乱句子顺序 | 理解句间关系并还原顺序 |
| Document Rotation 文档旋转变换 | 随机选一个 token 作为文档开头并旋转 | 找出原文真正的起始位置 |

多层次噪声迫使模型学习语法、语义和篇章结构，适配各种生成场景。实验表明 **Text Infilling 在下游任务中表现突出**，结合句子级去噪任务还能进一步提升。虽然预训练主要面向生成，BART 在许多理解任务上同样优异。

## 下游任务适配

BART 兼具文本表示和生成能力，不同类型的任务微调方式不同：

1. **序列分类（强调理解）**：输入同时送编码器和解码器，语义表示主要取**解码器最后时刻**的隐藏状态——通常在句末添加特殊标记，用该位置的隐状态接线性分类器预测标签，微调过程类似 BERT。
2. **生成任务**（摘要、生成式问答）：输入是任务定义的文本，解码器自回归生成目标输出，生成文本与目标文本之间的差异构成损失。
3. **机器翻译**：输入输出属于不同语言、不同词表，直接用生成式微调有局限。做法是在 BART 输入层前**增加一个小型 Transformer 编码器**，把源语言映射到目标语言的表示空间；为缓解扩展层与原模型训练不匹配，采用**分阶段训练**——先单独训练小型编码器，再与主模型联合微调。

## 优缺点

- 双向理解 + 自回归生成一体，摘要、翻译、对话等任务表现很强；
- encoder-decoder 结构在纯生成场景不如 decoder-only 简洁，后者更易扩展到超大模型，成为现代大语言模型的主流架构（见 [LLM 架构](/posts/nlp/07-01-llm-architecture/)）。
