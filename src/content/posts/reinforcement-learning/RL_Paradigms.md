复习要点第 2 条要求说清强化学习、监督学习、无监督学习的区别与联系。最容易记的一句话是：

> 监督学习"有人告诉正确答案"；无监督学习"没有答案，也不做决策"；强化学习"没有答案，只有试错后的分数，而且这个分数是延迟的"。

但这句话只够应付名词解释。真正要理解的是：三者在**数据从哪来、监督信号是什么、优化什么目标、要不要做序贯决策**这四个维度上不同。

## 一张表看区别

| 维度 | 监督学习 | 无监督学习 | 强化学习 |
| --- | --- | --- | --- |
| 数据来源 | 训练集事先给定 | 训练集事先给定 | 智能体与环境的交互自己产生 |
| 数据分布 | 通常假设 i.i.d. | 通常假设 i.i.d. | 非 i.i.d.：当前策略决定见到什么数据 |
| 监督信号 | 精确标签 $y$ | 没有标签，只有 $x$ | 标量奖励 $r$，模糊、延迟、可能稀疏 |
| 学习目标 | 拟合输入到输出的映射 | 发现数据结构、表示或密度 | 最大化长期折扣回报 |
| 是否决策 | 一次预测，预测完就结束 | 不涉及决策 | 序贯决策：当前动作改变未来状态分布 |
| 探索 | 不需要 | 不需要 | 必须平衡探索与利用 |
| 反馈时机 | 每个样本立刻有标签 | 无外部反馈 | 可能几百步后才拿到一个奖励 |
| 数据分布是否随模型变化 | 不变 | 不变 | 随策略变化，训练分布本身是学习系统的一部分 |
| 典型任务 | 分类、回归、SFT | 聚类、降维、密度估计、自监督预训练 | Q-learning、PPO、RLHF |

## 三者的目标函数

监督学习最小化经验风险：

$$
\min_\theta\ \frac1N\sum_{i=1}^N L\big(f_\theta(x_i),y_i\big).
$$

每个样本都有一张"标准答案"，误差可以逐样本计算。

无监督学习没有 $y$，目标变成发现结构。例如：

$$
\text{k-means：}\min_{\{\mathcal C_k,\mu_k\}}\sum_{k=1}^K\sum_{x\in\mathcal C_k}\|x-\mu_k\|^2,
$$

$$
\text{PCA：}\max_{W^\top W=I}\operatorname{tr}\big(W^\top\Sigma W\big),
$$

$$
\text{密度估计：}\max_\theta\sum_{i=1}^N\log p_\theta(x_i).
$$

自监督学习也属于这一族：标签由数据本身构造（例如预测下一个 token、掩码恢复），不需要人工标注。

强化学习最大化策略的期望折扣回报：

$$
\max_\theta\ J(\theta)
=\mathbb E_{\tau\sim\pi_\theta}\Big[\sum_{t=0}^{T-1}\gamma^t r_t\Big].
$$

这里的 $r_t$ 不是"这一步应该输出什么"的标签，而是"这一步做得有多好"的评价。**奖励是评价，不是指令**：它告诉你结果好不好，不告诉你正确动作是什么。

## 为什么 RL 不能直接当监督学习

### 没有逐步标签，只有延迟标量

监督学习每个样本都有 $y_i$；RL 一条轨迹只有一串奖励。若 500 步后才到达终点，前面 499 步都没有"这个动作对不对"的直接答案，只有"这条轨迹最终得了多少分"。

这就是信用分配问题：最终回报该归功于哪一步动作？策略梯度用 $G_t$ 或优势 $A_t$ 给动作加权，本质上是在没有逐步标签的情况下估计每一步的贡献。

### 数据分布随策略变化

监督学习的训练集和测试集来自同一个固定分布；RL 中当前策略决定访问哪些状态：

$$
(s,a)\sim d^\pi(s)\pi(a\mid s).
$$

策略一更新，状态访问分布就变，模型或价值函数遇到的是新数据。这不是普通的分布偏移，而是**数据分布本身是优化过程的一部分**。

### 必须探索

监督学习的监督信号只覆盖训练集分布；RL 的最优动作可能从未被当前策略尝试过。不探索，就永远得不到"这个动作其实更好"的数据。这就是为什么 RL 需要 ε-greedy、UCB、Thompson Sampling、内在奖励这些机制，而监督学习不需要。

### 目标不匹配

监督学习最小化一步预测误差；RL 关心长期回报。一个模型的一步预测误差很小，不代表它适合长期规划；一个动作的即时奖励很高，也不代表它长期最优。

## 联系：RL 内部大量使用监督与无监督组件

三种范式不是互斥的。一个 RL 系统内部通常同时包含监督学习模块和无监督式表示学习模块。

### RL 里的监督学习组件

| 组件 | 监督信号 | 为什么"像监督学习" |
| --- | --- | --- |
| 环境模型学习 | $(s_i,a_i)\to s_{i+1}$ 或残差 | 标准回归问题；见 [基于模型的强化学习](/posts/reinforcement-learning/rl_modelbased/) |
| 价值网络回归 | TD 目标 $y_t=r_t+\gamma(1-d_t)\max_{a'}Q(s_{t+1},a')$ | 用 MSE 拟合一个标量目标 |
| Critic 训练 | 回报或 n-step return | 回归到价值目标 |
| 行为克隆 / 模仿学习 | 专家动作 $a^{\mathrm{expert}}$ | 标准分类或回归 |
| 奖励模型训练 | 人类偏好标签 | 二分类/回归 |

但 DQN 不是普通监督学习：它的标签 $y_t$ 由网络自己算出，随参数移动；训练样本也不是 i.i.d. 的，而是来自不断变化的行为策略。**看起来像回归，实际上目标在动、数据分布在动。**

### RL 里的无监督/自监督组件

- **状态表示学习**：用自编码器、对比学习、随机网络把高维观测压成特征，本身没有奖励。
- **状态聚合与计数**：把连续状态离散化、聚类、哈希，用于计数型内在奖励。
- **新颖性度量**：RND、ICM 的特征预测误差，本质是自监督式的表示学习，只是误差被拿来当探索奖励。
- **世界模型的潜在编码**：先无监督地学一个压缩表示，再在潜在空间里做预测和规划。

这些模块没有外部标签，也没有任务奖励，属于无监督/自监督学习；它们为 RL 提供更好的状态表示或探索信号。

### 监督学习里的 RL 组件

大模型训练把三者串在了一起：

| 阶段 | 范式 | 在做什么 |
| --- | --- | --- |
| 预训练 | 自监督学习 | 预测下一个 token，学语言与世界知识 |
| SFT | 监督学习 | 用人工示范做指令微调 |
| 奖励模型 | 监督学习 | 用偏好比较训练打分器 |
| RLHF / PPO / GRPO | 强化学习 | 用奖励信号优化生成策略 |
| DPO | 偏好优化（介于 SL 与 RL 之间） | 直接用偏好对优化策略，不显式训练奖励模型、不做在线采样 |

RLHF 的细节见 [PPO](/posts/reinforcement-learning/ppo/)、[GRPO](/posts/reinforcement-learning/grpo/)、[RLHF 与 PPO](/posts/nlp/09-01-rlhf-ppo/) 和 [DPO](/posts/nlp/09-02-dpo/)。

## 几个容易混淆的边界案例

| 场景 | 为什么不是纯粹的监督学习 | 更准确的定位 |
| --- | --- | --- |
| 行为克隆 / 模仿学习 | 用专家轨迹做监督，但动作会影响未来状态；测试时一旦偏离专家分布，错误会累积 | 介于 SL 与 RL 之间；可用 DAgger 等交互式修正 |
| Offline RL | 数据固定，像监督学习；但目标是长期回报，动作改变未来分布 | 固定数据集上的 RL，需要处理分布偏移与保守性 |
| 自监督预训练 | 有"标签"，但标签由数据自己构造 | 无监督/自监督学习，不是 RL |
| DPO | 用偏好数据直接优化策略，不需要在线交互 | 偏好优化；常与 RLHF 对比，但不是标准 on-policy RL |
| 推荐系统 | 有用户反馈，但反馈受当前策略影响、有延迟 | 通常建模为 contextual bandit 或 RL |

一个简单的判断顺序：

1. 数据是固定的，还是有动作在改变数据分布？
2. 监督信号是逐样本标签，还是延迟标量奖励？
3. 目标是单步预测准确，还是长期累计回报？
4. 需不需要主动探索未见过的状态—动作？

四个问题里，只要"动作改变未来分布 + 延迟奖励 + 需要探索"同时出现，基本就是 RL 问题。

## 名词速查与一句话总结

| 名词 | 一句话 |
| --- | --- |
| 监督学习 | 有输入输出对，学一个映射 |
| 无监督学习 | 没有标签，学数据结构或表示 |
| 自监督学习 | 标签从数据本身构造，属于无监督一族 |
| 强化学习 | 序贯决策，用延迟标量奖励优化长期回报 |
| 行为克隆 | 把专家动作当标签的监督学习，但会遭遇分布偏移 |
| Offline RL | 数据固定、目标是长期回报的 RL |
| RLHF | 监督学习训奖励模型 + 强化学习优化策略 |

核心公式：

1. 监督学习：$\min_\theta\frac1N\sum_iL(f_\theta(x_i),y_i)$。
2. 无监督学习：$\max_\theta\sum_i\log p_\theta(x_i)$（或聚类/降维目标）。
3. 强化学习：$\max_\theta\mathbb E_{\tau\sim\pi_\theta}[\sum_t\gamma^tr_t]$。
4. 数据分布：$(s,a)\sim d^\pi(s)\pi(a\mid s)$，随策略变化。

一句话：**监督学习有答案，无监督学习没有答案也不做决策，强化学习没有答案、只有延迟的评价，而且它的数据分布由自己的策略决定。**
