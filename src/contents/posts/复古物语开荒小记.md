# 青铜时代之前

概要：

+ 收集基础物资：木棍，燧石，小石块，金属粒，菖蒲，干草，野生作物
+ 捏造并烧制陶器
+ 烧制木炭
+ 建造简易庇护所，在地窖进行食物保存

### 1. 前期植物

做出来小刀(knife)可以收割大部分植物，配方如下：  

+ tule $\longrightarrow$ 茅草(thach)  
+ 菖蒲（Cattails）$\longrightarrow$ 菖蒲（cattails）
+ 草 $\longrightarrow$ 干草  

  tule跟菖蒲生长环境相同，比较飞舞，但是能做屋顶，还挺好看  

+ 菖蒲＋马尾艹可以合成药膏，缓慢回血
+ 干草，菖蒲/纸莎草大部分配方都是通用的
+ 前期用篮子给背包扩容，篮子和小刀放在合成表里可以返回香蒲。

### 2. 火把

  在**手上**，**被放置后**燃烧时间只有48小时，但是将火把**塞进箱子或背包**中再拿出来又能再烧48小时（<del>无尽能源这一块</del> ）所以每天回家的时候把火把打掉塞进背包（**注意不能拿手上**）再拿出来放墙上就可以无限续杯。

### 3. 烧制木炭

建议$2*2*2$，一定要填满，烧完之后铲子可以快速收集

### 4. 关于粘土

有蓝色/红色粘土和耐火粘土。耐火粘土除了做耐火砖以外没啥特别的。  

耐火粘土如果找到了记得多收集一点，这玩意锻铁炉和烤箱都是刚需。找不到的话可以青铜时代里烧燧石，燧石烧完并磨碎后和普通粘土能合成。

+ 前期需要烧制的陶器：各种工具模具（优先镐子，锤子），砧模具（一个足够，随用随烧），锭模具（建议多烧），陶罐（大的，多烧），瓦罐（可选），坩埚（多烧），锅（两个足够），碗（多烧）

+ 泥炭是最优燃料（时间最短），没有泥炭的话，木炭和木材也可以
+ 窑坑容易引起火灾，尽量放水里，上面要挡住。

### 5. 食物保鲜

最好的保鲜是吃进肚子里。如果吃不下，可以放陶罐里和地窖里。注意，陶罐的保鲜可以和地窖叠加。关于**地窖参数**：

+ 容积最大$7*7*7$（此时保鲜效果也最好），可以不规则，棱上的方块不影响密闭空间判定。
+ 密封效果：最简陋的木门$\lt$（裸奔这一块） 其他门$\lt$ **活扳门** $\lt$直接封死 $\lt$ 锅炉门（升温这一块）。
+ 地窖的墙壁材质：玻璃(升温)$\lt$ 木头=金属 $\lt$ **石头=泥土**（各个种类的泥土）。  
  ps：**玻璃**的特性是让内部空间升温，虽然不能做地窖，但是可以做**温室**，堆肥也可以在温室中进行
+ 地窖内的光源（火把，火把架上的火把）不影响保鲜（有待验证），但太阳光除外（
+ 蔬菜和粮食在陶罐中保鲜效果最好，其他容器可以放水果，肉，饭，小瓦罐一个能存四份同样的菜品，小瓦罐+脂肪/蜡密封之后也有很好的保鲜效果（<del>太奢侈</del>  
  
对于吃不了的皮，前期可以用脂肪硬化处理，注意硬化之后的皮不能做皮革，但是可以做恶人专武投石索。

### 6.食物来源

蘑菇（吃之前看一眼描述，避免吃一口直接躺板板），浆果，鱼，芦苇根，种菜

关于温室：温室的效果是$+5^{\degree}C$，可以防止农作物冻死，但也可以把农作物热坏。

温室的顶棚玻璃面积不能少于百分之五十，可以用半砖节省材料

### 7.生火小寄巧

添加燃料只能提高火堆温度，燃料燃烧完之后火的温度会下降。刚开始可以**用便宜燃料来预热**，之后可以一次只加**一单位**的燃料避免浪费（当然直接all in木材也是无所谓的，但all in煤炭就很心疼了

### 8.前期矿物来源

主要是地表矿物，前期铜最重要。剩下的矿物可以标记日后再来，如果实在脸黑找不到铜，可以**小刀**加**原木**合成**淘沙盘**，在水里淘沙有概率获得金属粒

# 青铜时代

概要：

+ 解锁各种铜（二级）青铜（三级）金属工具，锤子，镐子，锯子，**凿子**还有镰刀刃都是很好用的工具（武器）。

+ 有了锯子可以解锁木板，进而获得**桶**，解锁**皮革**和**果汁**科技树
+ 铜不缺之后通过区块探矿寻找**锡**和**辉铋矿**等，解锁**青铜**（三级金属）
+ 盖**温室**，收获农作物，尝试养殖和养蜂。

### 1. 金属冶炼

+ 坩埚：用于1340以下的金属冶炼，高熔点金属需要熔炉和锻铁炉，合金的配比可以在生存手册里面查。  
烧纯金属的时候坩埚四个格子填满比一个格子烧的快

+ 铜砧可以敲青铜器，青铜砧可以敲铁，铁砧可以敲钢

+ 多余的锭可以用凿子（chisel）敲碎重新熔炼，凿子只能敲碎和凿子材料同等级的金属。凿子在砧上敲制，加上木柄可以获得烙铁（<del>不可逆</del>
+ 镰刀可以快速收割干草和菖蒲
+ 武器推荐长矛和弓+ 硬化后的皮可以做恶人专武投石索。

### 2. 探矿

参考这个：[【复古物语】游戏教程系列01 - 探矿指南](https://www.bilibili.com/video/BV1Kt421n72H/?share_source=copy_web&vd_source=508f9008633ddcfb01e9adad004516c4)  

+ 节点探矿模式：半径为六的立方体存在的矿石含量 （单位：块） (不能探测硝石，岩盐)

  微量|少量|中等|大量|巨大量|极多量(ultra)
  -----|----|----|----|----|----
  1~9|10~19|20~39|40~79|80~159|>160

+ 密度探矿：显示一个区块（32*32）所有可能出现的矿的生成概率(没显示就是没有)，最大数值是15&permil;，
  $1000*[千分比]$可以得到大致含矿量。在一次采样之后，往一个方向走80格（确保走出区块）然后继续探矿，通过比较密度来判定是否靠近大矿脉：如果密度上升或不变，就沿着该方向继续；如果密度下降，就返回上一个勘探节点并且换方向，直到探到形容词为“极多量”。
+ 在找到大矿脉之后，可以每隔8个格子（考虑到探矿半径6，人手挖掘距离是3，也可以结合矿盘平均半径确定）打一个竖井，并且根据矿物的**y轴比例系数**和**矿物生成基准面**来计算生成高度，在打竖井的过程中，每隔8个方块向四个方向用节点搜索。  
ps:关于锡矿的生成高度计算：y轴比例系数是0.4\~0.75，矿物生成基准面是表面（不是水平面，表面是脚底下的高度），假设人在y=95，那么锡矿就可能生成在38\~71.25高度之间

矿物种类|y轴比例系数|生成基准面|矿盘半径|
:-----:|:--------:|:-------:|:------:|
锡矿（深）|0.4~0.75|表面     |12 $\pm$ 3
铁矿（深）|0.05~0.85(y=5~93)|海平面 |26 $\pm$ 10

### 3.青铜

铜质工具（镐，砧等）只有二级，而青铜工具是三级，可以一直用到铁器时代结束。锡矿是冶炼青铜（bronze）必不可少的原材料。青铜有很多变体，每种变体侧重于不同属性（如耐久，攻击力等）并不存在哪一种材料绝对优于某一种。

前期青铜合金推荐锡+铜和辉铋矿+铜

### 4.皮革制作

皮革可以升级背包，也可以缝制盔甲，十分甚至九分的有用

+ 石灰：锤子砸石头，贝壳或者研磨
+ 药剂配方：  

    基础液体 |溶质| 制作 1 满桶|时间
    -------|---------|-----------|----
    50 L 水|50 石灰|石灰水|——
    50 L 水|20 硼砂粉|稀释的硼砂|——
    50 L 水|5 橡木/金合欢原木|弱单宁|一天
    50 L 弱单宁| 5 橡木/金合欢原木|强单宁|一天

+ 消耗比例：一个装有整50 L 溶液的桶可以处理多达：
  + 25 张小兽皮（每张兽皮 2 升，将使用所有溶液）
  + 12 张中等兽皮（每张兽皮 4 升，剩余 2 升）
  + 8 张大兽皮（每张兽皮 6 升，剩余 2 升）
  + 5 张巨大兽皮（每张皮 10 升，将使用所有溶液）
+ 步骤：

$$
\begin{aligned}
  \text{生皮}&{\xrightarrow[\text{一天}]{\text{石灰水}}}浸泡过的皮革\\[10bp]  
  &{\xrightarrow{\text{小刀}}}刮过的皮革\\[10bp]
  &\xrightarrow[三天]{\text{弱单宁}}鞣制过的皮\\[10bp]
  &{{\xrightarrow[\text{时间因皮革种类而异}]{\text{强单宁}}}}皮革
\end{aligned}
$$

### 5.耐火粘土

找不到可以烧燧石（前期的话燃料用木炭就足够），烧完产物放石磨里研磨，研磨产物和普通粘土合成耐火粘土。

锻铁炉的合成需要耐火砖。耐火粘土合成耐火砖，合成后耐火砖需要在**坑窑**里用**烧陶器的方法**烧制一遍才能用来合成别的。

烤箱（clay oven）需要**直接用耐火粘土捏制**，这玩意粘土用量巨大，建议多准备一点。
烤箱只能烤面包和派。

### 6.食物保存（果汁）

在进入铜器时代后可以获得锯子（锯子->木板->桶），也能在铁砧上敲出铜棒，去野外收集树脂+脂肪可以做出榨汁机。榨汁机可以延长水果保质期，也可以提高水果回复的饱食度。

+ 对于量少的水果建议当零食吃
+ 对于量多的水果可以榨汁，果汁可以存在大木桶中，在地窖里大概保存25天左右，一升果汁（一陶碗）回复两格（200点）饱食度。比例如下：
  $$
  32\text{个水果}\overset {\text{榨汁}}{\longrightarrow} 10L\text{对应水果汁+少量榨干的水果块（可以当饲料喂了）}\\[10bp]
  $$
+ 果汁可以进一步发酵形成果酒，果酒一升（一碗）80饱食度，比果汁要少，但胜在能永久保存。**果酒喝多了会头晕影响视觉**

### 7.温室

农作物温度过低或过高都会减产，温度低到一定程度会直接**冻死**无法收获。温室的效果是室内$+5^{\degree}C$，注意自己所在的区域，如果冬天不冷的话可以不用盖温室，（当然**太冷的话盖了也没用**）。有的植物（黑麦，萝卜/芜青）**适合低温生长**也**不用**种温室。

温室搭建：

+ 玻璃必须占温室顶面积的$50\%$，听说可以用半砖玻璃节省，但是建议用完整方块
+ 温室像地窖一样也需要**密封**，但门和活版门不影响温度，温室之间可以共用墙壁
+ 温室内部建议**分区**，方便作物**轮作**，分4~5块地就够
+ 留一块室外农田用来种耐低温作物

### 8.养蜂

收集蜜蜂：

+ 野生蜂巢周围有黄色粒子特效，在树干上时会有洞。靠近时会有嗡嗡声

+ 人工养殖密封用的是蜂箱，蜂箱用八个菖蒲＋一个粘土合成。蜂箱放在野生蜂巢半径5格以内，周围尽可能地多种花，可以吸引蜜蜂进入蜂箱。蜜蜂进入后会变成有蜜蜂的蜂箱，搬运有蜜蜂的蜂箱需要占用一个背包格。

养殖：

+ 蜂箱周围水平半径八格，上下半径五格内的花均可以被蜂箱识别

+ 建议栅栏围起来，防止小浣熊<del>小完能</del>破坏蜂巢
+ 收获时直接破坏蜂箱即可，获得初产物蜜脾。（注意破坏之后蜜蜂对周围一切生物均有仇恨，不要离牲口太近，可以用稻草人吸引仇恨）

蜜脾$\xrightarrow{对着容器挤压}0.2L$蜂蜜+1个蜜蜡

蜜蜡很有用，用来密封食物有点浪费，主要是制作无限光源蜡烛，进而制作提灯。

# 铁器时代

### 1. 铁的收集

+ 赤铁矿，黄铁矿需要3级⛏也就是锡铜合金⛏采集，陨铁需要四级⛏（铁镐）
+ 在沙漠中如果遇到比较规整的圆形坑（无所谓深度）可以往下挖两个方块有几率挖到陨铁（meteoric iron）

### 2. 锻铁

锻铁需要锻铁炉，锻铁炉需要打碎才能或的产物，材料回收率挺高的，但还是建议多做一些耐火砖。  

+ 赤铁矿 $\xrightarrow[木炭]{锻铁炉}$ 铁胚 ${\xrightarrow[\gt700^{\circ}]{熔炉}}$ 加热铁胚 ${\xrightarrow[随便来个锤子]{青铜砧}}$ 铁锭

+ 石英$\xrightarrow[木炭]{锻铁炉}$玻璃

## 附录3 战斗小技巧

+ 铜及铜以上的装备能一下敲死鱼，捕鱼必备

+ 打鹿这种跑得快的动物可以用恶人的投石索打最远距离，这样鹿跑一会就会停下来，方便追击。

+ 盾+镰刀刃可以无伤速通野怪

+ 弓的准度差，建议如果不是猎人还是不要玩弓，可以用恶人投石索替代，反正子弹不要钱。

+ 复古物语一般来说怪物是不会刷新在非完整方块上的，可以地上放石头避免刷怪，但**时空风暴**期间怪物会**无视亮度**，**无视地形**在**玩家周围**生成，可以搭[刷怪塔]( https://www.bilibili.com/video/BV1RD8Ee1E9Y/?share_source=copy_web&vd_source=508f9008633ddcfb01e9adad004516c4"简易万能刷怪塔")。（合理利用凿子制造有利地形）。
+ 家旁边挖壕沟可以有效聚怪。
